# Massive logic baseline

## 1. Dataset

Generated by `tests/test_logic_scale.cpp`:

```text
entities     20,000
kinds           256
facts         23,370
exceptions     2,858
queries        2,000
```

Facts are generic triples, not a hardcoded animal schema:

```text
(entityN, isa, kindK)
(kindK, can, ability0)
(kindK, isa, kindK+1)
(entityN, cannot, ability0)
```

The kind chain supports inheritance; exceptions override the inherited ability.

## 2. Baseline result

```text
correct   2000/2000
accuracy  100%
time      47 ms
```

The baseline is a deterministic triple store plus rule traversal. It is a
**reference**, not a learned model. It proves the generated logic is solvable and
gives the learned layers something fixed to beat or approximate.

## 3. Why “universal computation state space”

The store is predicate-generic:

- any subject/relation/object triple;
- arbitrary kind chains;
- exceptions at entity or kind level;
- traversal rules independent of the animal example.

This is the state-space side: the logic is data, not a special case in the
engine. The baseline is host symbolic; the topology/learner must eventually
represent and merge the same facts.

## 4. Training use

Use the generated triples as the massive logic corpus for:

- relation-qualified Hopfield associations;
- `WordMemory`-style relation bins;
- overbootstrap routing evidence;
- held-out logic queries.

Do not call a symbolic pass a learned result. Compare it to the 100% reference.
